건강보험 표준담보 DB 구축안

기초서류의 보장담보를 담보명·보장 정의·분류코드 기준으로 읽어 세부담보와 표준담보로 정규화하고, 회사별 보장여부·지급조건·면책/감액/대기기간을 한 기준으로 비교한다.

대상 서류: 사업방법서 · 보통/특별약관 · 산출방법서금액: 특약 보험가입금액 대비 %작성: 2026-10-14

하나생명 파일럿 반영: 상품요약서(2026.09.01) 3건의 특약 블록 566개 → 급부 806행 → 표준담보 83종 · 세부담보 143종. 요약서에는 분류코드가 없어 세부담보는 지급사유 문구로 판정했고, 약관 원문으로 재검증할 예정입니다.

1 · 문제 정의

트렌드 파악 비용이 크고, 수기 DB화 오류가 많다

업계 트렌드 파악에 드는 리소스

  • 회사마다 같은 보장을 다른 이름으로 판매(예: 뇌졸중진단비 / 뇌경색·뇌출혈진단비)해서 담보명만으로는 비교가 안 된다.
  • 신상품·개정 때마다 약관 별표의 분류코드 범위를 다시 읽어야 한다.
  • 담보 수가 많아(건강보험 1개 상품에 특약 100개 이상) 사람이 매번 전수 검토하기 어렵다.

DB화 과정의 오류 지점

  • 지급금액·횟수: 최초 1회 / 연간 1회 / 매회, 가입금액 대비 % 표기가 섞여 있다.
  • 면책: 보장개시일 기준(90일)과 계약일 기준이 혼재한다.
  • 감액: 기간(1년·2년)과 지급률(50%)이 문장 하나에 들어 있어 누락이 잦다.
  • 대기기간: 입원 n일 초과, 진단 후 생존 n일 등 지급요건이 약관 본문 곳곳에 흩어져 있다.
2 · 해결방안

정의·분류코드 기반 2단계 정규화

담보명은 회사가 정하는 마케팅 명칭이므로 키로 쓰지 않는다. 보장 정의(지급사유)와 분류코드를 읽어 세부담보를 확정하고, 세부담보의 공통 속성으로 표준담보를 묶는다.

  1. STEP 1담보 추출담보명, 보장 정의, 분류코드(KCD·수술분류표), 지급금액·횟수, 면책·감액·대기 문구와 원문 위치(서류·조·페이지)
  2. STEP 2정규화정의 문장의 표현 차이 제거, 분류코드를 개별 코드 집합으로 전개(C00–C97 → C00, C01 …)
  3. STEP 3세부담보명 부여매칭키가 같으면 회사가 달라도 같은 세부담보명을 쓴다
  4. STEP 4표준담보명 부여표준담보 기준 컬럼(보장사건·질병군·지급형태)으로 세부담보를 묶는다
  5. STEP 5검증규칙 검사 후 예외 건만 원문과 대조

세부담보 동일성 규칙

match_key = hash( 보장사건 + 정규화된_보장정의 + 정렬된_분류코드_집합 )

회사별 담보의 보장 정의와 분류코드가 같으면 같은 match_key를 가지므로, 같은 세부담보명과 표준담보명이 자동으로 붙는다. 코드 범위가 하나라도 다르면(예: 뇌졸중에 I64 포함 여부) 별도 세부담보로 분리한다.

표준담보 기준 컬럼

기준 컬럼값 예시판단 근거

범위 수식어고액 · 소액 · 특정 · 주요같은 질병군 안에서 분류코드가 부분집합인지 여부(세부담보명에만 반영)

표준담보명 = 질병군 + 보장사건 + 지급형태. 예: 뇌혈관 + 진단 + 정액 → “뇌혈관질환진단비”. 그 아래 세부담보는 범위 수식어와 분류코드로 구분한다.

오류를 줄이는 입력 규칙

  • 지급횟수는 코드로만 입력: FIRST1(최초 1회), YEAR1(연간 1회), EACH(매회), DAY(1일당)
  • 면책은 일수와 기산점(보장개시일/계약일)을 분리 저장
  • 감액은 기간(개월)과 지급률(%)을 분리 저장. 문구 원문도 함께 보관
  • 금액은 만원 단위 정수, 가입금액 대비 비율이면 기준금액을 별도 컬럼에

자동 검증 규칙

  • 같은 match_key 안에서 세부담보명이 2개 이상이면 오류
  • 암 계열 담보에 면책 없음 → 확인 대상으로 표시
  • 감액기간 ≥ 보험기간, 감액률 ∉ (0,100) → 오류
  • 유사암 진단비 > 일반암 진단비 → 확인 대상으로 표시
  • 분류코드가 어느 세부담보에도 매칭되지 않으면 신규 세부담보 후보로 등록

원천은 상품요약서 「보험금 지급사유 및 보험급부별 보험금 지급제한 사유」이고, 기존 DB와는 대조하지 않고 새로 추출했습니다. 상품 열은 요약서 단위이며, 한 요약서가 비갱신형·갱신형·R형 특약을 함께 다루므로 대표값을 쓰고 다른 값이 있으면 「외 n」으로 표시합니다. 금액은 특약 보험가입금액 대비 비율입니다.
